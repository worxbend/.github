Clusters

What I actually work on

Grouped by what the code does. One constellation each. Click to filter.

  • ◈

    Streaming & OBS

    Drive OBS from a CLI, a TUI or a GTK window. Twitch and YouTube chat in a terminal. Browser-source overlays. Built because clicking the mouse mid-stream is how you miss the moment.

    — Filter catalogue

  • ◇

    Air Quality

    One AirGradient sensor, eight clients: GTK desktop, Android, CLI, GNOME applet, e-paper, LED wall, TV dashboard, metrics stack. Eight is more than anyone needs. All over LAN, no cloud account.

    — Filter catalogue

  • ◆

    IoT & Edge

    ESP32 and ESP8266 firmware: cameras, relays, LED matrices. Raw TCP on the wire, no HTTP, no JSON, no broker. Half of these ship with the server on the other end of the socket.

    — Filter catalogue

  • ▣

    Linux & Provisioning

    Wiped disk to working workstation, driven from YAML in Git. Packages, dotfiles, fonts, pinned binaries. The same tool exists here four times in four languages, which is how I learned four languages.

    — Filter catalogue

  • ⬡

    Scala & JVM

    Scala 3: compile-time derivation, typed API clients, an auth server, Kafka and Flink pipelines. Plus two Lichess libraries ported to Flix, where one wrong bit corrupts every stored game.

    — Filter catalogue

  • ⬢

    CAD & 3D printing

    FreeCAD parts, printed to hold the hardware everything else here runs on. Camera housings, SBC mounts, brackets. Ugly, and they fit.
